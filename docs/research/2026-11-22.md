# Chorale: research findings

Research by five research agents, behind the plan. This is a snapshot: versions and tools move fast, so recheck anything here before depending on it.

The agents worked from web search and GitHub. Several official sites were blocked from the research session: `agentclientprotocol.com`, `antigravity.google`, `developers.googleblog.com`, `argmaxinc.com`, `sw.kovidgoyal.net` and `petal.aly.town`. Where a finding rests only on search snippets of those sites, it says so.

## Agent Client Protocol and adapters

ACP is maintained by the `agentclientprotocol` GitHub organisation, which Zed started. It is JSON-RPC 2.0 over an agent's standard input and output. The stable protocol version is 1. A version 2 draft was published around 2026-07-20, and clients negotiate it in `initialize`. High confidence for version 1.

The client sends `initialize`, `authenticate`, `session/new`, `session/load`, `session/prompt` and `session/cancel`. The agent calls back with `session/update`, `session/request_permission`, file reads and writes, and terminal methods, which the client turns on through `clientCapabilities`.

The Go library is `github.com/coder/acp-go-sdk`, Apache-2.0, maintained by Coder, at v0.20.0. It isn't official, it is pre-1.0, and v0.20.0 broke the v0.19 API.

The Claude Code adapter is `agentclientprotocol/claude-agent-acp`, npm package `@agentclientprotocol/claude-agent-acp`. It replaced `zed-industries/claude-code-acp`. It is built on the Claude Agent SDK and uses the existing `claude` login. An `ANTHROPIC_API_KEY` in its environment switches billing to the API. That last point is inferred from third-party docs, medium confidence.

The Codex adapter is `agentclientprotocol/codex-acp`. It drives the Codex App Server, bundles the Codex CLI, and accepts `CODEX_PATH` to use an installed one. Codex does not speak ACP natively. Medium-high confidence.

## Antigravity CLI

Antigravity CLI has spoken ACP natively since version 1.5.0, released around 2026-11-04, through `agy acp`. Version 1.5.12 was current around 2026-11-19. A recent 1.5 patch fixed `agy acp` turns hanging when a tool needed a second approval. High confidence on ACP support, from search snippets of Google's docs.

Its headless mode is `agy -p` with JSON or streaming JSON output. In headless mode, tools that need approval are refused, so ACP is the better route for answering each prompt.

Gemini CLI stopped serving Google AI Pro and Ultra subscribers on 2026-06-18. It still works with paid API keys, so it is not an option on Cami's subscription.

## Petal's code

Petal, at `github.com/alyraffauf/petal`, is MIT licensed. It uses Go 1.27.3, Bubble Tea v2.1.2 with Bubbles, Lip Gloss and Glamour v2, and `coder/acp-go-sdk` v0.20.0. It also uses cobra and viper, SQLite through modernc with goose and sqlc, `creack/pty`, and fsnotify.

The terminal interface talks over in-memory pipes to an embedded proxy that starts the adapters. Each adapter runs in its own process group, and stopping it kills the whole group. File access is confined to the project with `os.OpenRoot`. Permission requests become a Bubble Tea message carrying a reply channel. No restart or backoff code was found.

## Terminal interface and low vision

Bubble Tea v2.0.0 was released on 2026-02-24, and v2.1.2 is the latest, from 2026-11-18. Setting `KeyboardEnhancements.ReportEventTypes` gives separate key press and key release messages, and the app is told whether the terminal supports them. High confidence.

Key release reporting, through the Kitty keyboard protocol: Kitty yes, Ghostty yes, iTerm2 probably, WezTerm only with `enable_kitty_keyboard = true`, Alacritty unclear, Terminal.app no. Enter, Tab and Backspace report releases only in a stricter mode.

No published low-vision guidance for terminal interfaces was found. Claude Code's issue tracker has low-vision reports about fixed-width wrapping running text off screen at large font sizes, flicker causing eye strain, no text size setting, and output that ignores the screen size.

Claude Code's own accessibility settings are useful precedent: colour-blind themes, `prefersReducedMotion`, `CLAUDE_CODE_ACCESSIBILITY=1` to keep the cursor visible for magnifiers, a no-flicker mode, and a terminal bell. It has no high-contrast theme.

Colours given as the terminal's 16 ANSI colours come from the user's own palette. Fixed truecolour values ignore it. A contrast test is only meaningful for truecolour themes. The WCAG contrast formula is about fifteen lines of Go, so no library is needed.

## Local speech-to-text

The original Hex, `kitlangton/Hex`, is an archived MIT Swift app. It runs Parakeet through FluidAudio, and WhisperKit. Hex has moved to `anomalyco/hex`, a cross-platform rewrite with a vocabulary list, word replacements and an optional language-model cleanup step. Its press-and-hold, double-tap-to-lock interaction is worth copying.

FluidAudio is Apache-2.0 with permissively licensed models, runs on macOS and iOS, and transcribes Parakeet TDT about 190 times faster than real time on an M4 Pro. It has rare-word biasing in batch mode, not in its streaming model. High confidence.

WhisperKit is MIT. Its custom vocabulary and real-time features are paid. Apple's SpeechTranscriber needs macOS 26 or iOS 26. Its contextual strings reportedly affect only `DictationTranscriber`, not `SpeechTranscriber`. Benchmarks disagree on Apple against Parakeet, and none were found for an M1.

macOS charges microphone access to the launching app, normally the terminal. If that app doesn't declare microphone use, access is denied silently. Claude Code issues 82543 and 33023 report this.

## iOS companion

Prior art: Claude Code Remote Control with the Claude app, which is closed source, relays through Anthropic and covers only Claude. Codex in the ChatGPT app is also closed and relayed. Happy is MIT, has an end-to-end encrypted relay, supports Claude and Codex, and is the best project to study. Omnara is Apache-2.0 and dropped CLI wrapping as unmaintainable. VibeTunnel forwards a raw terminal, which is poor at large text sizes. CC Pocket puts approvals right on the session list.

The iOS Tailscale app is a full-device VPN, so any app can reach tailnet hosts while it is connected. Tailscale Serve gives a host an HTTPS address with a real certificate.

iOS suspends background sockets, so notifications must be pushed. Options: Apple's push service, which needs the paid developer account; ntfy; or Pushover, a one-off $4.99.

The Apple Developer Program costs $99 a year. Free accounts install apps that expire after seven days. TestFlight internal testing needs the paid program and skips App Store review.

Macs can't be woken reliably over Wi-Fi or across Tailscale, so the phone can only count on an always-on machine.

## Policy

Anthropic's legal page says Agent SDK developers should use API key authentication. It forbids third parties from offering Claude.ai login or routing requests through Pro or Max credentials for their users. It allows an end user to sign in to Claude Code with their own subscription. A personal tool used only by its author on her own login appears to fit.

## Addendum: Inkling 2 Mini

Added later, from web search only, not tested.

Thinking Machines Lab released Inkling 2 Mini on 2026-11-20 under Apache 2.0. It is a looped mixture-of-experts model with 26.4 billion total parameters and 3.4 billion active per token, and its checkpoint is about 20 GB. The model card lists Apple silicon Macs with at least 32 GB of memory, and quantized GGUF builds for llama.cpp. Ollama, LM Studio and llama.cpp support it in recent versions; older runtimes fail with an "unknown architecture" error. Its benchmark claims haven't been independently confirmed. Its larger sibling, Inkling 2 Small, has 594 billion parameters and is not a candidate for a Mac mini.
