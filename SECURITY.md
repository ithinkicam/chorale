# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately, not in a public issue or pull request. Use GitHub's private vulnerability reporting for this repo:

https://github.com/ithinkicam/chorale/security/advisories/new

The report reaches the maintainer only. Say what you found, how to reproduce it, and what an attacker could do with it. You'll get a reply on the advisory, and the fix and any credit are agreed there before anything is made public.

## Supported versions

Chorale has no releases yet. Only the `main` branch is supported, and fixes land there.
